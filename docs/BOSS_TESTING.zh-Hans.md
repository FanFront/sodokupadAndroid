# Sudokuvania 首领副本：离线迭代验收

## 范围与来源

- 翻译目录中已找到 20 个首领 Markdown 入口（第一部 9 个、第二部 11 个）。
- 同时发现约 50 个独立谜题链接（包括首领、敌人、序章、样例和简化版本）。
- 捕获须存储实际 HTML、游戏 API 的 scl 谜题数据及运行所需 JS/CSS；网络仍应被 Android 拦截器禁止回源。

## 自动检查

1. 触屏模拟：运行 node scripts/test-android-touch.mjs，验证区域/首领面板、可点击链接、界面遮罩及数字按键。
2. 资源闭环：运行 OFFLINE_REQUIRE_BOSS_PUZZLES=1 npm run verify，检查 20 个首领记录、API 谜题数据、HTML 注入的手机控制脚本。
3. 原有主线回放：运行 node scripts/replay-offline.mjs，确认地图不空白、核心数字按键可使用。
4. 构建后检查 app/src/main/assets/offline/capture-report.json 的 missingBossPages 为空数组；可接受非游戏分析请求失败，但不得遗漏副本题目数据。

## 真机验收

1. 断网启动两部主地图，填数、撤销、移动和放大缩小正常。
2. 选中已经探索的所属区域格子，打开「区域」，确认显示当前网格规则；打开「首领」，确认有相应可触摸链接。
3. 进入首领独立谜题，确认 9×9 棋盘处在可视区内，手机数字键可用，题目规则可读。
4. 副本填写一格后「返回」主地图，检查原地图进度和迷雾状态，重新进入该副本检查单独存档。
5. 未揭开迷雾的格子不应通过自制 UI 偷跑首领链接；未打包的资源须明确报错，绝不可静默联网。

注意：本次操作通过一次性提交标记触发 GitHub Actions 抓取。GitHub Actions 成功与 Android 真机交互是两道不同的验证，不能互相替代。第三方资源请检查版权与分发权限。
