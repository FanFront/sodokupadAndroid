# Sudokuvania 简体中文化：当前状态

本项目是非官方 Android 网页封装与辅助翻译工具，**不是两部游戏经过人工完整校对的中文移植版**。

## 目前可用

- Android 应用主菜单与简要规则指南：简体中文。
- SudokuPad 通用词汇：内置 66 条中英文对照。
- 游戏专用词汇：第一部 11 条、第二部 26 条。仅匹配完全相同的英文文本。
- 打开游戏后点击 **全文翻译**：首次会询问是否通过 Wi-Fi 下载英中机器翻译模型（约 30 MB）；模型就绪后，网页上可访问的英文文本会在手机上翻译成中文。
- 动态出现的剧情、任务、规则文字：在属于普通 HTML/SVG 可见文字节点时，也会尝试翻译。**不会提前解锁迷雾中的内容**。
- 如有规则歧义，再次点击 **显示英文** 即可还原该页面被本工具改写的英文文字。
- Android 进度存储沿用 SudokuPad 网页自身机制，本工具不会改写谜题 JSON/数独答案。

## 尚未完成或尚未验证

- 两部游戏**所有**剧情、任务、分支、隐藏规则、首领谜题说明尚未逐条提取并人工校对。未审校的条目依靠机器翻译，不能保证数学含义准确。
- 图片/Canvas、不可访问的 SVG 图形文字、部分工具提示、被拆分为多个标签的文字可能保留英文。
- 原站升级可能改变英文文本，从而导致原有精确词典不再匹配。
- APK 编译状态与 Android 真机长时游玩、手势操作、迷雾、存档的兼容性尚需实测。
- 第三方机器翻译模型可能把 “digit”（填入的数字）和 “value”（格子的数值）混为一谈；这两者在 Sudokuvania 中有时不同。遇到疑问务必核对英文原文。

## 如何维护未来游戏的中文化

1. 将新游戏加入 `app/src/main/assets/games.json`。
2. 把全局术语放入 `app/src/main/assets/i18n/zh-Hans.json`，游戏专用术语放入 `app/src/main/assets/i18n/games/<game-id>.zh-Hans.json`。
3. 词典的键必须是网页中确实出现的**英文原文**，值为经人工核对的简体中文；优先核对影响计算的规则与限定条件。
4. 使用动态翻译作为**兜底**，不能以机器翻译替代逐条审稿。尤其注意 “at least/exactly/only”、数字/数值、区域边界、相邻定义、动态迷雾、支线任务。
5. 如需离线捆绑或分发完整受版权保护的剧情内容，应先获得权利人许可，随后导入可审核的原文目录，并逐条审核文本与游戏内显示效果。
